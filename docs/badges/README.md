# Repository-owned badges

These SVGs are snapshots, not live counters. Their exact observation time is in `snapshot.json`. Downloads include only `.ipa` assets from published releases, including prereleases; wallpaper and source downloads are excluded.

Refresh with `python3 scripts/update-readme-badges.py` while authenticated with `gh`, update the date in the root README if necessary, then commit the SVGs and snapshot. No third-party badge service is required.
